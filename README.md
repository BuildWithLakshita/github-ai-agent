# GitHub AI Agent

Build your first GitHub AI Agent in under 100 lines of Python.

This project allows you to ask questions about any GitHub profile in natural language. The AI Agent automatically retrieves profile information from the GitHub API and generates an intelligent response.

## Requirements

- Python 3.10+
- OpenAI API Key

## Installation

Install the required packages.

```bash
pip install openai requests
```

Set your OpenAI API key.

```bash
export OPENAI_API_KEY=your_api_key
```

## Run

```bash
python main.py
```

## Example Prompt

```text
Analyze the GitHub profile of torvalds.
```

## Example Output

```text
Here is an analysis of Linus Torvalds' GitHub profile...
```
